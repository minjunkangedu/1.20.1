이 폴더가 "완성된 소스"입니다. 아래대로만 하면 됩니다.

──────────────────────────────
1) 새 저장소 만들기 (기존 꼬인 repo는 안 써도 됨)
   - github.com → 오른쪽 위 "+" → New repository
   - 이름 아무거나(예: voidhunt-mod) → Create repository

2) 이 폴더 "안의 내용물 전부"를 업로드
   - 이 zip을 압축 풀기
   - 새 저장소의 "uploading an existing file" 클릭
   - 압축 푼 폴더를 열고 → 안의 내용물 전부 선택(Ctrl+A) → 드래그
     (폴더째 말고, 그 안의 build.gradle·settings.gradle·src 등을)
   - 초록 "Commit changes"
   ※ 구조가 좀 달라도 괜찮게 만들어놨어요(빌드가 settings.gradle 있는
     폴더를 자동으로 찾아서 돎). 딱 하나, 아래 3번만 꼭 지켜주세요.

3) ★ 워크플로 파일은 "루트에" 직접 만들기 (제일 확실)
   - 저장소 메인 → Add file → Create new file
   - 파일 이름 칸에 정확히:  .github/workflows/build.yml
   - 압축 안의 .github/workflows/build.yml 을 메모장으로 열어
     내용 전체 복사 → 붙여넣기 → Commit
   (GitHub은 이 파일이 "저장소 맨 위 .github/workflows" 에 있어야만
    자동 빌드를 돌립니다. 그래서 이건 직접 만드는 게 확실해요.)

4) 자동 빌드 → jar 받기
   - 상단 Actions 탭 → 새 작업이 돎
   - 초록 체크 = 성공 → 그 작업 맨 아래 Artifacts → VoidHunt-mod-jar 다운
   - 압축 풀면  voidhunt-1.0.0.jar  ← 진짜 모드
   - 빨간 X = Build 단계 로그의 error: 부분 스크린샷 → 나한테

5) 게임에 설치 (서버 아님, 내 게임!)
   - 내 마크에 Fabric 설치(fabricmc.net, 1.21.4)
   - .minecraft/mods 에  voidhunt-1.0.0.jar  +  Fabric API(1.21.4)  같이
   - 실행 → /give @s voidhunt:void_shades → 우클릭 착용 → H로 토글

문제 생기면 그 화면 스크린샷 하나면 이어서 도와드려요.
